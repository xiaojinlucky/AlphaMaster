# WO-AM-07B 裁决：replay 价格层资格与训练最小长度解耦（2026-07-26 归因 / 2026-07-27 落笔）

## 裁决

**484 根最小 K 线数是训练合同参数，不是数据质量缺陷判据，不适用于组合回放（replay）的价格层。**

依据：`scripts/build_csi300_historical_am_inputs_v3.py` 的 `classify_status`（约 264–281 行）把 `source_rows < 484` 的股票打成 quarantine——该阈值来源是训练最小样本长度要求（warmup 252 + 训练/验证切分的可行长度），保护的是"能不能训练"，与"成分期内每个交易日有没有可信价格"无关。回放价格层的真实需求只有后者。

三只均为次新股：数据从上市起完整覆盖各自的成分期，唯一"缺陷"是上市时间短。

## v4 覆盖矩阵新增列定义：`replay_price_eligible`

- 语义：该股票在其成分期内的 qfq 价格序列可作为组合回放的估值/成交价格源。
- 取值规则（逐只判定，写入 v4 覆盖矩阵，独立于训练资格列）：
  1. `status == available` → true；
  2. `status == quarantine` 且 reasons **仅含** `minimum_bars` 且 `source_covers_membership_span == true` → true（即本裁决三只）；
  3. 经 WO-AM-07A 修复并通过逐只审计的股票 → true（审计记录 ID 必须写入该行）；
  4. 其余 → false。
- 边界：本列**不**改变训练资格（三只仍不可入训练批次）；**不**回写 v3（v3 零字节改动铁证=其 manifest SHA-256 `e07fffd04c9d53a897ae688ad05897a03273acf14010f799e1aca85579a8404c` 不变）；`source_missing`（990018）永远 false。
- 每次升级必须携带独立审计记录（v3 基线状态 / 升级依据 / 证据指针），禁止无记录升级——对齐 RND-04A 裁决的禁止声明第 7 条（不静默升级）。

## 效果

本裁决 + 07A 首批修复共同解锁 2026-01-23~2026-06-30 的 6 个时点（首个真实全量回放区间）；单独生效时按状态层口径闭合 2025-06-30 起 13 个时点中三只次新股造成的缺口。
