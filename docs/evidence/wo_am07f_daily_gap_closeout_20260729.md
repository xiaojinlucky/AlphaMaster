# WO-AM-07F 日级漏数正式收口

时间：2026-07-27 复核，2026-07-29 形成公开审查摘要。

## 结论

- 成分窗口内缺口共 29,616 个代码-日期点。
- 显式停牌 29,479 个点；真漏数 137 个点。
- 真漏数涉及 8 只股票，在回放范围 `2006-10-31` 至 `2026-06-30`
  内威胁 136 个不同交易日。
- 其余 4,642 个交易日形成 7 段连续安全区间：
  1. `2006-10-31` 至 `2015-08-04`，2,132 日；
  2. `2015-08-06` 至 `2017-07-13`，471 日；
  3. `2017-07-17` 至 `2018-06-29`，234 日；
  4. `2019-01-07` 至 `2020-04-10`，306 日；
  5. `2020-04-14` 至 `2023-06-14`，770 日；
  6. `2023-06-16` 至 `2026-05-22`，708 日；
  7. `2026-05-26` 至 `2026-06-24`，21 日。

## 分类合同

1. 只统计股票处于沪深 300 成分窗口内的冻结交易日。
2. 在对应 v3 D1 文件首末日期范围内缺少 bar 的日期进入缺口集合。
3. 缺口命中冻结 `suspended_days.h5` 的精确证券键与日期时分类为
   `suspended`，否则分类为 `true_missing`。
4. 安全区间按冻结交易日历的相邻交易日分段；周末和法定休市不切段。
5. 显式停牌可以在执行层拒单后继续回放，因此不计入威胁日。
